# Support

Flagstage Core is self-hosted software. These files are not a support contract.

| You want to…           | Go here                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| Ask a question         | [Discussions](https://github.com/rera/flagstage-core/discussions)                            |
| Report a bug           | [Bug issue](https://github.com/rera/flagstage-core/issues/new/choose)                        |
| Propose a feature      | Start in Discussions. Open a feature issue once the change has a shape.                      |
| Report a vulnerability | [SECURITY.md](SECURITY.md). Use private vulnerability reporting. Do not open a public issue. |
| Run or upgrade a site  | [docs/](docs/index.md), including getting started, deploy, DNS, and upgrading.               |
| Change the code        | [CONTRIBUTING.md](CONTRIBUTING.md)                                                           |

`flagstage doctor` prints whether the environment, database, storage, and Bedrock access are configured. Redact secrets before you paste logs.
