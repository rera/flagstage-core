# Forms and analytics

Lead forms post to `/f/{siteId}/{formKey}`. Import points a site's own forms, including forms on its subdomains, at that endpoint. Search, login, comment, checkout, and file-upload forms on that site are removed. Overview lists each one, and any form that still points at the old site. Go live is not refused for that list. The route accepts any text field name. Uploaded files are not stored. The browser is allowed only when its origin host is one of the site's hostnames or `{slug}.{base domain}`. A non-empty `website` field is dropped. Each address gets a small token bucket in Postgres. Stored submissions can be downloaded as CSV from the site. The same submission is mailed through SES to `FORM_NOTIFY_EMAIL` and to any addresses stored on the form.

Analytics is one script tag added when a change is published, and removed on the next publish when analytics is off for the site. The script sends the path and referrer to `/a/collect`. Visitors are a daily hash of the address and user agent. Raw events are deleted after 48 hours, once an hourly job has added them to the daily totals. The site page shows 7, 30, and 90 day totals and the top pages. There are no cookies and no chart.
