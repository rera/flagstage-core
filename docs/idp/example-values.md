# Example values

This table is documentation. Flagstage Core has no vendor-specific identity client. Confirm each value on the identity provider's own screen before you paste it. The generic steps are [OIDC](oidc.md) and [SAML](saml.md).

`{APP_URL}` is the app origin. `{providerId}` is the id you type in Flagstage. The redirect and ACS URLs are the same for every provider.

| Field in Flagstage  | Okta                                                                                                                                   | Entra ID                                                                               | Google Workspace                                                                          |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Provider id         | A short id you choose, such as `staff`.                                                                                                | Same.                                                                                  | Same.                                                                                     |
| Email domain        | The domain on staff email addresses.                                                                                                   | Same.                                                                                  | Same.                                                                                     |
| OIDC issuer         | `https://{your-domain}/oauth2/default` for the default custom authorization server. Use the issuer shown on that server if it differs. | `https://login.microsoftonline.com/{tenant-id}/v2.0`                                   | `https://accounts.google.com`                                                             |
| OIDC redirect URI   | `{APP_URL}/api/auth/sso/callback/{providerId}`                                                                                         | Same. Paste it into the app's redirect URI.                                            | Same. Paste it into the authorized redirect URI.                                          |
| Groups claim        | A claim named `groups` whose values are group ids.                                                                                     | Optional groups claim. The values Flagstage matches are object ids, not display names. | The default token does not include groups. Send an attribute named `groups`, or use SAML. |
| SAML sign-on URL    | The IdP single sign-on URL from the application.                                                                                       | The Login URL from the enterprise application.                                         | The SSO URL from the custom SAML app.                                                     |
| SAML ACS URL        | `{APP_URL}/api/auth/sso/saml2/sp/acs/{providerId}`                                                                                     | Same. Paste it into Reply URL.                                                         | Same. Paste it into ACS URL.                                                              |
| SAML issuer         | The IdP entity id. Not the ACS URL.                                                                                                    | The Identifier (entity id) from the enterprise application.                            | The Entity ID from the SAML app.                                                          |
| Signing certificate | The IdP X.509 certificate.                                                                                                             | Same.                                                                                  | Same.                                                                                     |

Flagstage appends `/.well-known/openid-configuration` to the OIDC issuer and fetches it while saving. The app has to be able to reach that URL.
