# Site edits

Prefer an include when the same block is on many pages.

- `find_pages` — path glob, text, selector, or a JSON-LD field
- `read_page` — one page
- `edit_include` — a file under `_inc/`
- `set_meta` — set or remove a JSON-LD field
- `retag` — add or remove a tag in JSON-LD and in the visible tags
- `replace_text` — replace text
- `list_links` — find or rewrite links
