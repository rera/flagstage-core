# Governance

Flagstage Core is maintained by the [rera](https://github.com/rera) organization. `.github/CODEOWNERS` names `@rera` for the whole tree.

## Decisions

Product and technical constraints live in the docs and in the code that enforces them. A change that contradicts a written constraint needs a doc update in the same pull request. There is no separate steering committee.

## Releases

Version numbers come from [Changesets](https://github.com/changesets/changesets). The steps, including the multi-arch container image, are written in [docs/ci/release.md](docs/ci/release.md). That recipe is not wired on this branch. Nothing here tags a release or pushes an image.

## Conduct and security

The [code of conduct](CODE_OF_CONDUCT.md) applies to issues, discussions, and pull requests. Report a vulnerability the way [SECURITY.md](SECURITY.md) describes. That path is GitHub private vulnerability reporting, not a public issue.

## Funding

There is no `FUNDING.yml`. This repository does not list sponsors.
