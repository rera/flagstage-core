# Trademark policy

"Flagstage" and the Flagstage logo are trademarks of Rera.

The Apache License, Version 2.0 does not grant trademark rights. This file
says how the name and logo may be used.

## Allowed

- Unmodified redistribution of Flagstage Core, with this policy and `NOTICE` kept intact.
- A "Powered by Flagstage" link to https://flagstage.com in the application interface, as shipped.
- Stating, accurately, that a deployment is based on Flagstage Core.

## Not allowed

- Using the Flagstage name or logo on a modified public distribution in a way that implies Rera's endorsement.
- Registering domains, product names, or social accounts that suggest an unofficial build is the official project.

## Forks

Forks that ship modified builds publicly should choose a different name and logo. Keep the `NOTICE` attribution.

Questions: open a GitHub Discussion, or write to the security contact in `SECURITY.md` if the matter is confidential.
